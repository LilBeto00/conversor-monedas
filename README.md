# Conversor de monedas

Web instalable en el móvil (PWA) para convertir yenes, euros, dólares y cualquier otra moneda.

- Tipos de cambio de [ExchangeRate-API](https://www.exchangerate-api.com) (gratis, se actualizan una vez al día).
- Funciona sin conexión con los últimos tipos guardados.
- Para probarla en local: `python -m http.server 5173` y abre http://localhost:5173
